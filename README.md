## 오픈 미션 - 간단한 게시판 만들기

## 기능 요구 사항

간단한 게시판을 구현한다.

* 사용자는 게시글을 등록, 조회, 수정, 삭제할 수 있다.
* 게시글은 **제목(title)**, **내용(content)**, **작성자(author)**, **작성일(createdAt)**, **수정일(updatedAt)** 정보를 가진다.
* 모든 데이터는 서버에 저장된다 (메모리 DB 또는 H2 사용).
* 게시글의 CRUD 동작은 REST API로 제공한다.
* React 프론트엔드에서 이 API를 호출해 게시판 화면을 구성할 수 있도록 한다.
* 사용자가 잘못된 요청을 보낼 경우 `IllegalArgumentException` 등을 발생시키고, `"[ERROR]"`로 시작하는 에러 메시지를 반환한다.
* 예외 발생 시, 클라이언트가 다시 입력할 수 있도록 명확한 에러 메시지를 전달한다.

---

## 기능 목록

### [x] 게시글 작성 (Create)

* [x] 사용자로부터 게시글 제목, 내용, 작성자 입력 받기
* [x] 제목과 내용이 비어있는 경우 예외 발생 (`[ERROR] 제목과 내용은 필수입니다.`)
* [x] 작성일(`createdAt`)을 현재 시간으로 자동 설정
* [x] 게시글 저장 후 생성된 게시글 ID 반환

### [x] 게시글 목록 조회

* [x] 등록된 모든 게시글 조회
* [x] 최신 작성일 순으로 정렬
* [x] 게시글 ID, 제목, 작성자, 작성일 정보를 함께 반환

### [x] 게시글 상세 조회

* [x] 게시글 ID로 단일 게시글 조회
* [x] 존재하지 않는 게시글 ID 조회 시 예외 발생 (`[ERROR] 존재하지 않는 게시글입니다.`)

### [x] 게시글 수정

* [x] 게시글 ID로 수정 대상 조회
* [x] 제목과 내용 수정 가능 (작성자는 변경 불가)
* [x] 수정일 갱신
* [x] 존재하지 않는 게시글 수정 시 예외 발생 (`[ERROR] 존재하지 않는 게시글입니다.`)

### [x] 게시글 삭제

* [x] 게시글 ID로 삭제 수행
* [x] 존재하지 않는 게시글 삭제 시 예외 발생 (`[ERROR] 존재하지 않는 게시글입니다.`)
* [x] 삭제 성공 시 성공 메시지 반환

## 예외 처리

* [x] 제목이나 내용이 공백인 경우
* [x] 게시글 ID가 존재하지 않는 경우
* [x] 게시글 ID가 숫자가 아닌 경우

## API 명세 (요약)

| 기능        | Method   | URL               | 요청 본문                                                   | 응답 예시                                                                                |
| --------- | -------- | ----------------- | ------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| 게시글 등록    | `POST`   | `/api/posts`      | `{ "title": "...", "content": "...", "author": "..." }` | `{ "id": 1, "title": "...", "author": "...", "createdAt": "..." }`                   |
| 게시글 목록 조회 | `GET`    | `/api/posts`      | -                                                       | `[ { "id": 1, "title": "...", "author": "...", "createdAt": "..." } ]`               |
| 게시글 상세 조회 | `GET`    | `/api/posts/{id}` | -                                                       | `{ "id": 1, "title": "...", "content": "...", "author": "...", "createdAt": "..." }` |
| 게시글 수정    | `PUT`    | `/api/posts/{id}` | `{ "title": "...", "content": "..." }`                  | `{ "id": 1, "title": "...", "content": "...", "updatedAt": "..." }`                  |
| 게시글 삭제    | `DELETE` | `/api/posts/{id}` | -                                                       | `{ "message": "게시글이 삭제되었습니다." }`                                                     |
